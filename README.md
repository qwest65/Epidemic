# Epidemic — эпидемия на случайном графе

Интерактивная симуляция распространения инфекции по сети контактов.
Модель болезни — **SEIR**, сеть контактов — случайный граф **Эрдёша — Реньи G(n, p)**.

**Онлайн:** https://qwest65.github.io/Epidemic/

Всё приложение — один файл [`index.html`](index.html): HTML + CSS + JavaScript, без сборки и без сервера.
Библиотеки подключаются с CDN jsDelivr:

| Библиотека | Версия | Для чего |
|---|---|---|
| [D3.js](https://d3js.org/) | 7.9.0 | раскладка графа (`d3-force`), масштаб и сдвиг (`d3-zoom`) |
| [Chart.js](https://www.chartjs.org/) | 4.4.1 | график динамики S / E / I / R |

## Интерфейс

Экран разделён на три зоны:

```
┌──────────────┬─────────────────────────┬──────────────────────┐
│  Панель      │                         │  Счётчики и          │
│  параметров  │    Граф контактов       │  показатели          │
│  и кнопки    │    (Canvas, zoom/pan)   ├──────────────────────┤
│              │                         │  График S/E/I/R      │
└──────────────┴─────────────────────────┴──────────────────────┘
```

- **Слева** — кнопки управления и все параметры модели.
- **В центре** — сеть контактов: каждый кружок — человек, линия — контакт. Цвет кружка — его состояние.
- **Справа сверху** — текущий день, количество людей в каждой группе, ключевые показатели и оценка R₀.
- **Справа снизу** — график, как менялись группы по дням.

Вёрстка адаптивная: на экранах уже 1200 px статистика и график уходят под граф,
уже 760 px — все блоки выстраиваются в одну колонку (удобно на телефоне).

Цвета состояний:

| Состояние | Цвет | Смысл |
|---|---|---|
| **S** — Susceptible | синий | здоров, может заразиться |
| **E** — Exposed | оранжевый | заражён, инкубационный период, симптомов нет |
| **I** — Infected | красный | болен и заразен |
| **R** — Recovered | зелёный | выздоровел, иммунитет, больше не заражается |

## Параметры

### Сеть контактов
Изменение любого из этих параметров **строит новый граф** и сбрасывает симуляцию.

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Количество людей **N** | 20 – 300 | 100 | число вершин графа |
| Среднее число контактов **k** | 0.5 – 15 | 4 | сколько в среднем знакомых у человека. Вероятность ребра считается как `p = k / (N − 1)` и показывается под ползунком |
| **Seed** | целое ≥ 0 | 42 | «зерно» генератора случайных чисел. Один seed — один и тот же граф и один и тот же ход эпидемии. 🎲 — случайный seed |

Если `k < 1`, под ползунком появляется предупреждение: сеть распадается на мелкие «острова»
и эпидемия не может охватить заметную часть людей (подробнее — в разделе [Граф](#1-построение-графа)).

### Болезнь
Изменение этих параметров **сбрасывает симуляцию на том же графе** с теми же нулевыми пациентами —
так можно честно сравнивать сценарии.

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Вероятность заражения **β** | 1 – 100 % | 20 % | шанс заразиться за один день от **одного** больного соседа |
| Инкубационный период **E** | 0 – 14 дней | 3 | сколько дней человек заражён, но ещё не болен. **0** — стадии E нет, модель превращается в SIR |
| Продолжительность болезни **I** | 1 – 21 день | 7 | сколько дней человек болен и заразен |
| ☐ Заразен в инкубации | вкл/выкл | выкл | если включено, люди в состоянии E тоже заражают соседей (бессимптомные носители) |
| ☐ Случайные длительности | вкл/выкл | выкл | если включено, длительность E и I у каждого своя, случайная, а заданное значение — среднее |

### Симуляция

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Период симуляции | 10 – 180 дней | 60 | сколько дней моделировать; задаёт и длину оси X на графике |
| Начальных заражённых | 1 – 10 | 2 | сколько людей больны в день 0 («нулевые пациенты»). Выбираются случайно среди людей, у которых есть хотя бы один контакт |
| ☑ Показывать цепочки заражения | вкл/выкл | вкл | рисовать красными линиями, кто кого заразил |
| Скорость | 0.5 – 20 дн/с | 4 | сколько дней симуляции проходит за секунду при автозапуске |

## Управление

| Кнопка / клавиша | Действие |
|---|---|
| **▶ Старт / ❚❚ Пауза** или `Пробел` | запустить или остановить автоматическую симуляцию |
| **+1 день** или `→` | сделать один шаг (один день); автозапуск при этом останавливается |
| **↺ Сброс** | вернуться к дню 0 на том же графе с теми же нулевыми пациентами |
| **Новый граф** | выбрать случайный seed и построить новую сеть |
| **🎲** | то же — случайный seed и новый граф |
| **⤢ Вписать** | вписать весь граф в окно |

Симуляция останавливается сама, когда достигнут последний день периода.

## Граф контактов

- **Масштаб** — колесо мыши (или щипок на тачскрине), **сдвиг** — перетаскивание.
- **Наведение на узел** показывает подсказку:
  номер человека, статус, число контактов, сколько дней осталось в текущем статусе,
  в какой день заразился, кто его заразил, скольких заразил он сам.
  Контакты наведённого узла подсвечиваются синим.
- **Клик по узлу в день 0** добавляет его в нулевые пациенты или убирает из них
  (хотя бы один должен остаться). Нулевые пациенты обведены белым кольцом.
  После старта менять их нельзя — сначала нажмите «Сброс».
- **Красные линии** — цепочки заражения: линия соединяет заразившего и заразившегося.
  Вместе они образуют «дерево заражения», растущее от нулевых пациентов.
- Расположение узлов вычисляет физическая модель (`d3-force`): связанные узлы притягиваются,
  все узлы отталкиваются друг от друга. Поэтому тесно связанные группы оказываются рядом,
  а одиночки — по краям. Положение узлов на расчёт эпидемии **не влияет** — важны только связи.

## Статистика

| Показатель | Что значит |
|---|---|
| **День X из Y** + полоса прогресса | текущий день и длина периода |
| Статус справа | «Готово к запуску», «Идёт симуляция…», «Пауза», «Эпидемия закончилась на N-й день» или «Период симуляции завершён» |
| Карточки **S / E / I / R** | сколько людей сейчас в каждой группе, в штуках и процентах от N |
| **Пик больных** | максимальное число одновременно больных (I) и день, когда он впервые достигнут |
| **Всего заражено** | сколько людей хоть раз заразились: `N − S` (включая тех, кто уже выздоровел) |
| **R₀ (оценка)** | базовое репродуктивное число — сколько людей в среднем заражает один больной в полностью здоровой сети (формула ниже) |
| **Рёбер / факт. k** | сколько контактов получилось в графе и фактическое среднее число контактов `2·рёбер / N` (из-за случайности немного отличается от заданного k) |
| **Макс. компонента** | размер самой большой связной группы людей. Болезнь не может выйти за пределы компоненты, в которой стартовала |
| **Изолированных** | люди без единого контакта — они никогда не заболеют |

Под показателями — цветная подсказка по R₀:

- **R₀ > 1.05** (красная) — вспышка, скорее всего, охватит заметную часть сети, хотя может и случайно затухнуть в первые дни;
- **0.95 ≤ R₀ ≤ 1.05** (оранжевая) — пограничный режим, исход сильно зависит от случая;
- **R₀ < 0.95** (зелёная) — эпидемия, скорее всего, быстро затухнет.

## График динамики

- График с накоплением (stacked area): снизу вверх **I**, **E**, **R**, **S**.
  Высота каждого слоя — размер группы, а вместе они всегда дают N.
  Больные специально внизу, чтобы форма «горба» эпидемии читалась сразу.
- Ось X сразу размечена на весь период (от 0 до заданного числа дней), кривые дорисовываются в реальном времени.
- Наведение на график показывает точные значения всех групп за выбранный день.
- Если эпидемия закончилась раньше конца периода, оставшиеся дни заполняются итоговыми значениями.

## Как работает модель

### 1. Построение графа
Используется модель Эрдёша — Реньи **G(n, p)**: для каждой из `N·(N−1)/2` возможных пар людей
независимо «подбрасывается монетка», и с вероятностью `p` между ними возникает контакт.

Вместо `p` пользователь задаёт **среднее число контактов k**, а `p` вычисляется как `p = k / (N − 1)`.
Так поведение сети не меняется резко при изменении N: при k = 4 у человека в среднем 4 знакомых
и при N = 50, и при N = 300.

Важное свойство G(n, p) — **фазовый переход при k = 1**:
- при `k < 1` граф состоит из множества маленьких несвязанных кусочков;
- при `k > 1` появляется **гигантская компонента**, объединяющая большую часть людей.

Эпидемия может стать массовой только при наличии гигантской компоненты — это хорошо видно,
если подвигать ползунок k около 1 и смотреть на показатель «Макс. компонента».

### 2. Состояния и переходы
Каждый человек находится в одном из четырёх состояний: `S → E → I → R`.

```
   заражение от соседа          инкубация D_E дней       болезнь D_I дней
S ──────────────────────► E ────────────────────────► I ───────────────────► R
   вероятность 1−(1−β)^m
```

Если инкубационный период равен 0, заразившийся сразу переходит в I (модель SIR).

### 3. Один шаг = один день
Обновление **синхронное**: состояния на день `t + 1` вычисляются по «снимку» дня `t`,
поэтому порядок обхода людей не влияет на результат. За один шаг для каждого человека:

- **S (здоров):** считается `m` — число заразных соседей (больных I, а при включённой опции — ещё и E).
  Если `m > 0`, человек заражается с вероятностью

  ```
  P(заражение) = 1 − (1 − β)^m
  ```

  Это вероятность того, что хотя бы один из `m` контактов передал болезнь, если каждый передаёт
  независимо с вероятностью β. Чем больше больных соседей, тем выше риск.
  Заразившийся переходит в E (или сразу в I при D_E = 0). Кто именно его заразил,
  выбирается случайно среди заразных соседей — это нужно для цепочек заражения и подсказок.
- **E (инкубация):** счётчик дней уменьшается; когда он доходит до нуля, человек переходит в I.
- **I (болен):** счётчик уменьшается; когда он доходит до нуля, человек переходит в R.
- **R (выздоровел):** больше не меняется.

### 4. Длительности
- **Фиксированные** (по умолчанию): заразившийся в день `t` находится в E ровно `D_E` дней,
  затем ровно `D_I` дней в I. Нулевые пациенты стартуют сразу в состоянии I в день 0.

  Пример при D_E = 3, D_I = 7: заразился в день 5 → E в дни 5–7 → I в дни 8–14 → R с дня 15.
- **Случайные:** длительность для каждого человека берётся из геометрического распределения
  со средним `D` (минимум 1 день). Большинство болеет около среднего, но бывают и короткие,
  и затяжные случаи — это ближе к реальности и делает кривые более плавными.

### 5. Окончание
Симуляция идёт до последнего дня периода. Если раньше этого не осталось ни одного человека в E и I,
эпидемия считается закончившейся: статус показывает её последний день, а график дозаполняется
итоговыми значениями до конца периода.

### 6. Оценка R₀
Вероятность того, что больной передаст болезнь конкретному соседу за всё время своей заразности:

```
T = 1 − (1 − β)^D,   где D = D_I   (или D_I + D_E, если заразен в инкубации)
```

Для графа Эрдёша — Реньи число степеней распределено по Пуассону, и среднее число «новых» соседей
у заразившегося равно `k`. Отсюда оценка:

```
R₀ ≈ T · k_факт
```

Пример с параметрами по умолчанию (β = 20 %, D_I = 7, k ≈ 3.5):
`T = 1 − 0.8⁷ ≈ 0.79`, `R₀ ≈ 0.79 · 3.5 ≈ 2.8` — ожидается массовая вспышка.

Это приближённая оценка: она не учитывает, что соседи больного могут быть уже заражены,
и при случайных длительностях менее точна.

## Воспроизводимость и seed

Вместо встроенного `Math.random()` используется собственный генератор псевдослучайных чисел
**mulberry32**, инициализируемый seed. От seed образуются три независимых потока случайности:

| Поток | Что определяет |
|---|---|
| `seed` | какие рёбра есть в графе |
| `seed · 7919 + 17` | кто будет нулевыми пациентами |
| `seed XOR 0x9e3779b9` | ход эпидемии: кто заразился, от кого, длительности |

Поэтому:
- одинаковый seed и параметры → **точно такой же** граф и **точно такой же** ход эпидемии,
  на любом компьютере. Результат можно показать другому человеку, просто сообщив seed;
- «Сброс» повторяет прогон один в один;
- изменение β или длительностей при том же seed даёт тот же граф и тех же нулевых пациентов —
  меняется только болезнь.

## Устройство кода

Весь JavaScript находится в одном блоке `<script>` в конце `index.html`, разделённом на секции:

| Секция | Содержимое |
|---|---|
| `constants & helpers` | цвета состояний, генератор mulberry32, склонение слова «день» |
| `params` | чтение значений ползунков в объект `P` и обновление подписей |
| `graph` | `buildGraph()` — генерация рёбер, поиск компонент (обход в глубину), выбор нулевых пациентов, запуск `d3-force` |
| `simulation` | `resetSim()`, `step()`, `record()` — состояние хранится в типизированных массивах `state`, `timer`, `infBy`, `infDay` |
| `playback` | автозапуск через `requestAnimationFrame` с шагом `1000 / скорость` мс |
| `chart` | создание и обновление графика Chart.js |
| `stats` | `refresh()` — счётчики, показатели, оценка R₀, статус |
| `drawing` | отрисовка на Canvas: рёбра, цепочки заражения, узлы (группами по цвету), кольца нулевых пациентов. Учитывается плотность пикселей экрана (Retina) |
| `zoom / pan / hover` | `d3-zoom`, поиск узла под курсором, всплывающая подсказка, клик по узлу |
| `wiring` | обработчики ползунков, кнопок и клавиш |

Граф рисуется на `<canvas>`, а не в SVG: при сотнях узлов и тысячах рёбер Canvas работает заметно быстрее.

## Пример эксперимента

1. **Порог связности.** N = 200, β = 50 %. Поставьте k = 0.8 и запустите — болезнь остаётся в маленьком «острове».
   Поставьте k = 2 — появляется гигантская компонента, и эпидемия охватывает большую часть сети.
2. **Роль β.** k = 4, D_I = 7. Сравните β = 3 % (R₀ < 1, вспышка гаснет) и β = 20 % (R₀ ≈ 3, массовая эпидемия).
3. **Бессимптомные носители.** Включите «Заразен в инкубации» при том же seed — пик наступает раньше и выше.
4. **Случай решает.** Установите параметры с R₀ около 1 и перебирайте seed кубиком 🎲:
   в одних прогонах эпидемия гаснет сразу, в других — разрастается.

## Ограничения

- Граф статичен: контакты не меняются со временем.
- Иммунитет после болезни пожизненный, повторного заражения нет.
- Нет смертности, вакцинации, карантина и других мер — это возможные направления развития.
- Модель учебная и не предназначена для реальных эпидемиологических прогнозов.
