# Epidemic

Интерактивная симуляция эпидемии (модель **SEIR**) на случайном графе Эрдёша — Реньи **G(n, p)**.
Всё приложение — один файл [`index.html`](index.html) без сборки (D3.js + Chart.js с CDN).

## Запуск
- Открыть `index.html` в браузере, или
- GitHub Pages: *Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`*.

## Модель
- Граф: N вершин, каждое ребро возникает с вероятностью `p = k / (N − 1)`, где `k` — среднее число контактов.
  При `k < 1` гигантской компоненты нет и эпидемия не может охватить сеть.
- Шаг = 1 день, все узлы обновляются синхронно по состоянию предыдущего дня.
- Здоровый узел с `m` заразными соседями заражается с вероятностью `1 − (1 − β)^m` и переходит в **E**.
- **E** длится `D_E` дней (0 = модель SIR), затем **I** длится `D_I` дней, затем **R** (иммунитет).
- Опции: заразность в инкубации; случайные (геометрические) длительности со средним `D_E`, `D_I`.
- Оценка базового репродуктивного числа: `R₀ ≈ (1 − (1 − β)^D) · k`.
- Seed делает граф и прогон воспроизводимыми.

## Возможности
- Zoom / pan графа, подсказка по наведению, клик по узлу в день 0 — назначить/снять нулевого пациента.
- Подсветка цепочек заражения («кто кого заразил»).
- Накопленный график S/E/I/R, счётчики, пик эпидемии, доля переболевших, размер крупнейшей компоненты.
- Горячие клавиши: `Пробел` — старт/пауза, `→` — +1 день.
