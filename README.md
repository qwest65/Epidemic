# Epidemic — эпидемия на случайном графе

Интерактивная симуляция распространения инфекции по сети контактов.
Модель болезни — **SEIR**, сеть контактов — случайный граф **Эрдёша — Реньи G(n, p)**.

**Онлайн:** https://qwest65.github.io/Epidemic/

> 👉 **Впервые здесь?** Простая инструкция без формул — [GUIDE.md](GUIDE.md).

Всё приложение — один файл [`index.html`](index.html): HTML + CSS + JavaScript, без сборки и без сервера.
Библиотеки подключаются с CDN jsDelivr:

| Библиотека | Версия | Для чего |
|---|---|---|
| [D3.js](https://d3js.org/) | 7.9.0 | раскладка графа (`d3-force`), масштаб и сдвиг (`d3-zoom`) |
| [Chart.js](https://www.chartjs.org/) | 4.4.1 | график динамики S / E / I / R и график сравнения прогнозов |

## Интерфейс

Верхний экран разделён на три зоны, под ним — блок сравнения прогнозов:

```
┌──────────────┬─────────────────────────┬──────────────────────┐
│  Панель      │                         │  Счётчики и          │
│  параметров  │    Граф контактов       │  показатели          │
│  и кнопки    │    (Canvas, zoom/pan)   ├──────────────────────┤
│              │                         │  График S/E/I/R      │
├──────────────┴─────────────────────────┴──────────────────────┤
│  Сравнение прогнозов: список · график с наложением · таблица  │
└───────────────────────────────────────────────────────────────┘
```

- **Слева** — кнопки управления и все параметры модели.
- **В центре** — сеть контактов: каждый кружок — человек, линия — контакт. Цвет кружка — его состояние.
- **Справа сверху** — текущий день, количество людей в каждой группе, ключевые показатели и оценка R₀.
- **Справа снизу** — график, как менялись группы по дням.
- **Внизу страницы** — сравнение сохранённых прогнозов (ссылка «Сравнение прогнозов ↓» в шапке).

Вёрстка адаптивная: на экранах уже 1200 px статистика и график уходят под граф,
уже 760 px — все блоки выстраиваются в одну колонку (удобно на телефоне).

Цвета состояний:

| Состояние | Цвет | Смысл |
|---|---|---|
| **S** — Susceptible | синий | здоров, может заразиться |
| **E** — Exposed | оранжевый | заражён, инкубационный период, симптомов нет |
| **I** — Infected | красный | болен и заразен |
| **R** — Recovered | зелёный | выздоровел, иммунитет, больше не заражается |

Форма значка показывает возраст: **квадрат** — ребёнок, **ромб** — подросток, **круг** — взрослый.

## Параметры

### Болезнь
Болезнь выбирается переключателем. У готовых болезней все параметры заложены заранее,
вариант **«Своя»** открывает ползунки (при переключении на него ползунки заполняются значениями
болезни, выбранной перед этим). Смена болезни **сбрасывает симуляцию на том же графе**
с теми же нулевыми пациентами — так сценарии можно честно сравнивать.

| Болезнь | β, % за день контакта | Заразен, дней | Инкубация, дней: дети / подростки / взрослые | R₀ при k = 4* |
|---|---|---|---|---|
| ОРВИ | 13 | 6 | 2 / 2 / 3 | ≈ 2.3 |
| Грипп | 9 | 6 | 1 / 2 / 2 | ≈ 1.8 |
| **COVID-19** (по умолчанию) | 16 | 9 | 6 / 5 / 5 | ≈ 3.2 |
| Своя | 1 – 100 | 1 – 21 | 0 – 14 для каждой группы | — |

\* R₀ считается программой по фактическому графу, см. [Оценка R₀](#7-оценка-r₀).

> **Откуда числа.** Значения подобраны для учебной модели и являются **приближёнными**.
> В справочниках для болезней приводят R₀ и диапазоны инкубационного периода
> (ОРВИ 1–3 дня, грипп 1–4 дня, COVID-19 2–14 дней, в среднем около 5).
> «β за день контакта» в справочниках не встречается — оно подобрано так, чтобы при k = 4
> получался R₀, близкий к наблюдаемому. Различия инкубации по возрасту — допущение модели.
> Для исследовательской работы значения стоит сверить с источниками (ВОЗ, Роспотребнадзор, CDC) и при необходимости
> задать через «Своя».

Дополнительно:

| Параметр | По умолчанию | Описание |
|---|---|---|
| ☐ Заразен в инкубации | выкл | люди в состоянии E тоже заражают соседей (бессимптомные носители) |
| ☐ Случайные длительности | выкл | длительность E и I у каждого своя, случайная, а заданное значение — среднее |

### Население

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Количество людей **N** | 20 – 900 | 100 | число вершин графа; изменение строит новый граф |
| Дети | 0 – 100 % | 20 % | доля детей |
| Подростки | 0 – 100 % | 15 % | доля подростков (вместе с детьми не больше 100 %) |
| Взрослые | остаток | 65 % | считается автоматически; цветная полоска показывает состав |

Возраст влияет на **инкубационный период** человека (см. таблицу болезней).
Изменение долей не меняет граф и нулевых пациентов — меняются только возрасты людей.

### Сеть контактов
Изменение любого из этих параметров **строит новый граф** и сбрасывает симуляцию.

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Среднее число контактов **k** | 0.5 – 15 | 4 | сколько в среднем знакомых у человека. Вероятность ребра считается как `p = k / (N − 1)` и показывается под ползунком |
| **Seed** | целое ≥ 0 | 42 | «зерно» генератора случайных чисел. Один seed — один и тот же граф, состав по возрастам и ход эпидемии. 🎲 — случайный seed |

Если `k < 1`, под ползунком появляется предупреждение: сеть распадается на мелкие «острова»
и эпидемия не может охватить заметную часть людей (подробнее — в разделе [Граф](#1-построение-графа)).

### Симуляция

| Параметр | Диапазон | По умолчанию | Описание |
|---|---|---|---|
| Дата начала (день 0) | любая дата | сегодня | календарная дата первого дня. По ней подписывается ось графика, показываются дата текущего дня, пика и окончания. Расчёт от даты не зависит |
| Период симуляции | 10 – 90 дней | 60 | сколько дней моделировать; задаёт и длину оси X на графике |
| Начальных заражённых | 1 – 100 (не больше N) | 2 | сколько людей больны в день 0 («нулевые пациенты»). Выбираются случайно среди людей, у которых есть хотя бы один контакт |
| ☑ Показывать цепочки заражения | вкл/выкл | вкл | рисовать красными линиями, кто кого заразил |
| Скорость | 0.5 – 20 дн/с | 4 | сколько дней симуляции проходит за секунду при автозапуске |

## Управление

| Кнопка / клавиша | Действие |
|---|---|
| **▶ Старт / ❚❚ Пауза** или `Пробел` | запустить или остановить автоматическую симуляцию |
| **+1 день** или `→` | сделать один шаг (один день); автозапуск при этом останавливается |
| **↺ Сброс** | вернуться к дню 0 на том же графе с теми же нулевыми пациентами |
| **Новый граф** | выбрать случайный seed и построить новую сеть |
| **🎲** | то же — случайный seed и новый граф |
| **⤢ Вписать** | вписать весь граф в окно |
| **💾 Сохранить прогноз для сравнения** | рассчитать текущий сценарий до конца периода и добавить его в [сравнение](#сравнение-прогнозов) |
| ☐ **Усреднить по 20 прогонам** | при сохранении посчитать сценарий 20 раз и сохранить среднее и разброс |

Симуляция останавливается сама, когда достигнут последний день периода.

## Эффекты и режимы показа

| Кнопка / настройка | Что делает |
|---|---|
| ✨ **Анимация заражений и эффекты** | при заражении по линии знакомства от больного летит «искра», в момент попадания расходится волна, цвет меняется плавно; больные пульсируют красным свечением, люди в инкубации светятся оранжевым; счётчики плавно «бегут»; при прохождении пика появляется подпись. По умолчанию выключено, если в системе включено «уменьшить движение» |
| 🎬 **Демо** | демонстрация для выступления: камера приближается к нулевым пациентам и затем следует за эпидемией, внизу появляются подписи (первая передача, 10 % города, половина города, пик, итог по возрастам). Скорость в демо не выше 2,5 дн/с. Остановить — «Пауза» или повторное нажатие |
| 🌳 **Дерево** | люди плавно перестраиваются в радиальное дерево заражения: в центре нулевые пациенты, кольца — поколения (кто кого заразил). Дерево растёт по ходу симуляции; незаражённые стоят по внешнему кругу. Повторное нажатие возвращает сеть |
| ⛶ | граф во весь экран (удобно для проектора) |

Красная точка в заголовке пульсирует, пока идёт симуляция. При сохранении прогноза линии на графике сравнения прорисовываются слева направо.

## Граф контактов

- **Масштаб** — колесо мыши (или щипок на тачскрине), **сдвиг** — перетаскивание.
- **Наведение на узел** показывает подсказку:
  номер человека, возраст, статус, число контактов, его инкубационный период, сколько дней осталось в текущем статусе,
  в какой день заразился, кто его заразил, скольких заразил он сам.
  Контакты наведённого узла подсвечиваются синим.
- **Клик по узлу в день 0** добавляет его в нулевые пациенты или убирает из них
  (хотя бы один должен остаться). Нулевые пациенты обведены белым кольцом.
  После старта менять их нельзя — сначала нажмите «Сброс».
- **Красные линии** — цепочки заражения: линия соединяет заразившего и заразившегося.
  Вместе они образуют «дерево заражения», растущее от нулевых пациентов.
- Расположение узлов вычисляет физическая модель (`d3-force`): связанные узлы притягиваются,
  все узлы отталкиваются друг от друга. Поэтому тесно связанные группы оказываются рядом,
  а одиночки — по краям. Положение узлов на расчёт эпидемии **не влияет** — важны только связи.

## Статистика

| Показатель | Что значит |
|---|---|
| **День X из Y** + полоса прогресса | текущий день и длина периода |
| Статус справа | «Готово к запуску», «Идёт симуляция…», «Пауза», «Эпидемия закончилась на N-й день» или «Период симуляции завершён» |
| Карточки **S / E / I / R** | сколько людей сейчас в каждой группе, в штуках и процентах от N |
| **Пик больных** | максимальное число одновременно больных (I) и день, когда он впервые достигнут |
| **Всего заражено** | сколько людей хоть раз заразились: `N − S` (включая тех, кто уже выздоровел) |
| **Заражено по возрастам** | какая доля детей, подростков и взрослых уже заразилась |
| **R₀ (оценка)** | базовое репродуктивное число — сколько людей в среднем заражает один больной в полностью здоровой сети (формула ниже) |
| **Рёбер / факт. k** | сколько контактов получилось в графе и фактическое среднее число контактов `2·рёбер / N` (из-за случайности немного отличается от заданного k) |
| **Макс. компонента** | размер самой большой связной группы людей. Болезнь не может выйти за пределы компоненты, в которой стартовала |
| **Изолированных** | люди без единого контакта — они никогда не заболеют |

Под показателями — цветная подсказка по R₀:

- **R₀ > 1.05** (красная) — вспышка, скорее всего, охватит заметную часть сети, хотя может и случайно затухнуть в первые дни;
- **0.95 ≤ R₀ ≤ 1.05** (оранжевая) — пограничный режим, исход сильно зависит от случая;
- **R₀ < 0.95** (зелёная) — эпидемия, скорее всего, быстро затухнет.

## График динамики

- График с накоплением (stacked area): снизу вверх **I**, **E**, **R**, **S**.
  Высота каждого слоя — размер группы, а вместе они всегда дают N.
  Больные специально внизу, чтобы форма «горба» эпидемии читалась сразу.
- Ось X сразу размечена на весь период (от 0 до заданного числа дней), кривые дорисовываются в реальном времени.
- Наведение на график показывает точные значения всех групп за выбранный день.
- Если эпидемия закончилась раньше конца периода, оставшиеся дни заполняются итоговыми значениями.

## Сравнение прогнозов

Главный инструмент для исследования: позволяет посчитать несколько сценариев и сравнить их на одном графике.

**Как пользоваться**
1. Настройте параметры (например, COVID-19, обычный состав населения).
2. Нажмите **«💾 Сохранить прогноз для сравнения»**. Сценарий мгновенно рассчитывается до конца периода —
   ждать анимацию не нужно — и появляется в блоке «Сравнение прогнозов» внизу страницы.
3. Измените одно условие (например, выберите «Грипп» или увеличьте долю детей) и снова сохраните.
4. Сравните графики и таблицу. Можно хранить до **5 прогнозов**.

Сохраняется именно то, что показывает анимация: при том же seed первый расчёт прогноза совпадает с анимированным прогоном день в день.

**Список прогнозов** (слева): у каждого свой цвет. Название можно изменить, щёлкнув по нему; ✕ удаляет прогноз.
У каждого прогноза **своя дата начала** — она берётся из поля «Дата начала» при сохранении и меняется прямо в карточке
(под ней показана дата окончания периода).
Прогнозы сохраняются в браузере (`localStorage`) и остаются после перезагрузки страницы,
но только на этом компьютере и в этом браузере.

**График с наложением.** Каждый прогноз — своя линия, сравниваются значения **в каждый день**.

Ось X переключается:
- **По датам** (по умолчанию) — общая календарная ось от самой ранней даты начала до самой поздней даты окончания;
  каждый прогноз стоит в своём периоде. Так можно, например, сравнить волну с 1 октября и волну с 15 ноября.
- **По дням от начала** — все прогнозы совмещены по дню 0, удобно сравнивать форму и скорость волн.

Что показывать:

| Кнопка | Что на графике |
|---|---|
| Больные | сколько людей болеют (I) в этот день — «волна» эпидемии |
| Новые за день | сколько человек заразилось именно в этот день (заболеваемость) |
| Всего заражено | сколько людей переболело или болеет с начала эпидемии (накопительно) |
| Инкубация / Здоровые / Выздоровели | численность групп E, S, R |

- **в % от населения** — проценты вместо человек; нужно, если в прогнозах разное N.
- **показать текущий прогон** — добавляет пунктиром анимированный прогон, чтобы сравнить его с сохранёнными «вживую».
- Наведение на день показывает значения всех прогнозов и **разницу** каждого с первым прогнозом.

**Усреднение по 20 прогонам.** Одна симуляция — это один случайный исход. Если перед сохранением отметить
«Усреднить по 20 прогонам», сценарий считается 20 раз на том же графе с теми же нулевыми пациентами,
но с разной случайностью заражений. На графике рисуется **средняя линия** и **полупрозрачная полоса разброса**
(от 10-го до 90-го перцентиля: в 8 из 10 прогонов значение попадало в полосу).
В таблице результаты показываются как «среднее (от–до)». Для выводов в исследовательской работе лучше использовать усреднённые прогнозы.

**Таблица сравнения.** Параметры прогнозов в столбцах рядом (включая дату начала); **отличающиеся параметры выделены**.
Ниже — результаты: пик больных (человек и % населения), день и дата пика, всего заражено,
доля заразившихся детей, подростков и взрослых, закончилась ли эпидемия до конца периода.

**Честное сравнение.** Если в прогнозах разные город (N, k, seed, состав населения или нулевые пациенты),
под графиком появляется предупреждение: разница в результатах тогда может объясняться не только болезнью.

**Экспорт для работы**
- **⬇ График PNG** — картинка 1600 × 900 на белом фоне с заголовком и легендой, удобная для вставки в документ.
- **⬇ Данные CSV** — таблица для Excel: сначала параметры и результаты, затем значения всех групп
  для каждого прогноза — по календарным датам (в режиме «По датам», ячейки вне периода прогноза пустые)
  или по дням от начала. Разделитель — точка с запятой, десятичная запятая, кодировка UTF-8 — файл открывается в русском Excel без настроек.

## Как работает модель

### 1. Построение графа
Используется модель Эрдёша — Реньи **G(n, p)**: для каждой из `N·(N−1)/2` возможных пар людей
независимо «подбрасывается монетка», и с вероятностью `p` между ними возникает контакт.

Вместо `p` пользователь задаёт **среднее число контактов k**, а `p` вычисляется как `p = k / (N − 1)`.
Так поведение сети не меняется резко при изменении N: при k = 4 у человека в среднем 4 знакомых
и при N = 50, и при N = 900.

Важное свойство G(n, p) — **фазовый переход при k = 1**:
- при `k < 1` граф состоит из множества маленьких несвязанных кусочков;
- при `k > 1` появляется **гигантская компонента**, объединяющая большую часть людей.

Эпидемия может стать массовой только при наличии гигантской компоненты — это хорошо видно,
если подвигать ползунок k около 1 и смотреть на показатель «Макс. компонента».

### 2. Состояния и переходы
Каждый человек находится в одном из четырёх состояний: `S → E → I → R`.

```
   заражение от соседа          инкубация D_E дней       болезнь D_I дней
S ──────────────────────► E ────────────────────────► I ───────────────────► R
   вероятность 1−(1−β)^m
```

Длительность инкубации `D_E` зависит от болезни **и возраста** человека, длительность болезни `D_I` — только от болезни.
Если инкубационный период равен 0, заразившийся сразу переходит в I (модель SIR).

### 3. Возраст
Каждому человеку при построении города назначается возраст: люди перемешиваются генератором случайных чисел
(seed), и первые `N · доля_детей` становятся детьми, следующие `N · доля_подростков` — подростками,
остальные — взрослыми. Возраст не влияет на то, с кем человек знаком, — только на его инкубационный период.

### 4. Один шаг = один день
Обновление **синхронное**: состояния на день `t + 1` вычисляются по «снимку» дня `t`,
поэтому порядок обхода людей не влияет на результат. За один шаг для каждого человека:

- **S (здоров):** считается `m` — число заразных соседей (больных I, а при включённой опции — ещё и E).
  Если `m > 0`, человек заражается с вероятностью

  ```
  P(заражение) = 1 − (1 − β)^m
  ```

  Это вероятность того, что хотя бы один из `m` контактов передал болезнь, если каждый передаёт
  независимо с вероятностью β. Чем больше больных соседей, тем выше риск.
  Заразившийся переходит в E (или сразу в I при D_E = 0). Кто именно его заразил,
  выбирается случайно среди заразных соседей — это нужно для цепочек заражения и подсказок.
- **E (инкубация):** счётчик дней уменьшается; когда он доходит до нуля, человек переходит в I.
- **I (болен):** счётчик уменьшается; когда он доходит до нуля, человек переходит в R.
- **R (выздоровел):** больше не меняется.

### 5. Длительности
- **Фиксированные** (по умолчанию): заразившийся в день `t` находится в E ровно `D_E` дней (своё значение для его возраста),
  затем ровно `D_I` дней в I. Нулевые пациенты стартуют сразу в состоянии I в день 0.

  Пример при D_E = 3, D_I = 7: заразился в день 5 → E в дни 5–7 → I в дни 8–14 → R с дня 15.
- **Случайные:** длительность для каждого человека берётся из геометрического распределения
  со средним `D` (минимум 1 день). Большинство болеет около среднего, но бывают и короткие,
  и затяжные случаи — это ближе к реальности и делает кривые более плавными.

### 6. Окончание
Симуляция идёт до последнего дня периода. Если раньше этого не осталось ни одного человека в E и I,
эпидемия считается закончившейся: статус показывает её последний день, а график дозаполняется
итоговыми значениями до конца периода.

### 7. Оценка R₀
Вероятность того, что больной передаст болезнь конкретному соседу за всё время своей заразности:

```
T = 1 − (1 − β)^D,   где D = D_I   (или D_I + D_E, если заразен в инкубации;
                                     D_E — средняя по населению с учётом долей возрастов)
```

Для графа Эрдёша — Реньи число степеней распределено по Пуассону, и среднее число «новых» соседей
у заразившегося равно `k`. Отсюда оценка:

```
R₀ ≈ T · k_факт
```

Пример для COVID-19 (β = 16 %, D_I = 9, k ≈ 4):
`T = 1 − 0.84⁹ ≈ 0.79`, `R₀ ≈ 0.79 · 4 ≈ 3.2` — ожидается массовая вспышка.

Следствие модели: `T ≤ 1`, поэтому **R₀ не может быть больше среднего числа контактов k**.
Очень заразные болезни (например, корь с R₀ 12–18) правдоподобно выглядят только при большом k.

Это приближённая оценка: она не учитывает, что соседи больного могут быть уже заражены,
и при случайных длительностях менее точна.

## Воспроизводимость и seed

Вместо встроенного `Math.random()` используется собственный генератор псевдослучайных чисел
**mulberry32**, инициализируемый seed. От seed образуются независимые потоки случайности:

| Поток | Что определяет |
|---|---|
| `seed` | какие рёбра есть в графе |
| `seed · 31 + 5` | возраст каждого человека |
| `seed · 7919 + 17` | кто будет нулевыми пациентами |
| `seed XOR 0x9e3779b9` | ход эпидемии: кто заразился, от кого, длительности |
| `(seed XOR 0x9e3779b9) + r · 0x6D2B79F5` | ход эпидемии в r-м прогоне при усреднении (r = 0 совпадает с анимацией) |

Поэтому:
- одинаковый seed и параметры → **точно такой же** граф и **точно такой же** ход эпидемии,
  на любом компьютере. Результат можно показать другому человеку, просто сообщив seed;
- «Сброс» повторяет прогон один в один;
- смена болезни или её параметров при том же seed даёт тот же граф, тот же состав и тех же нулевых пациентов —
  меняется только болезнь. Это и делает сравнение прогнозов честным.

## Устройство кода

Весь JavaScript находится в одном блоке `<script>` в конце `index.html`, разделённом на секции:

| Секция | Содержимое |
|---|---|
| `constants & helpers` | цвета, **таблица болезней `DISEASES`** (β, длительность болезни, инкубация по возрастам), генератор mulberry32 |
| `params` | чтение значений ползунков и переключателей в объект `P` и обновление подписей |
| `graph & population` | `buildGraph()` — рёбра, компоненты связности, `assignAges()` — возрасты, `pickInitial()` — нулевые пациенты, запуск `d3-force` |
| `simulation core` | `createSim()`, `simStep()`, `record()` — одна симуляция как объект с типизированными массивами `state`, `timer`, `infBy`, `infDay` и историей по дням. Этот же код используется и для анимации, и для расчёта сохраняемых прогнозов |
| `animated run` | `resetSim()`, автозапуск через `requestAnimationFrame` |
| `current-run chart` / `stats` | график Chart.js и `refresh()` — счётчики, показатели, оценка R₀ |
| `drawing` | отрисовка на Canvas: рёбра, цепочки заражения, значки людей (цвет = состояние, форма = возраст) |
| `zoom / pan / hover` | `d3-zoom`, подсказка, клик по узлу |
| `forecasts (comparison)` | `saveForecast()` → `runOnce()` × 1 или 20 → `aggregate()` (среднее, 10-й и 90-й перцентили); график сравнения, таблица, экспорт PNG и CSV, хранение в `localStorage` |
| `wiring` | обработчики ползунков, кнопок и клавиш |

Граф рисуется на `<canvas>`, а не в SVG: при сотнях узлов и тысячах рёбер Canvas работает заметно быстрее.

## Пример эксперимента

1. **Порог связности.** N = 200, β = 50 %. Поставьте k = 0.8 и запустите — болезнь остаётся в маленьком «острове».
   Поставьте k = 2 — появляется гигантская компонента, и эпидемия охватывает большую часть сети.
2. **Роль β.** k = 4, D_I = 7. Сравните β = 3 % (R₀ < 1, вспышка гаснет) и β = 20 % (R₀ ≈ 3, массовая эпидемия).
3. **Бессимптомные носители.** Включите «Заразен в инкубации» при том же seed — пик наступает раньше и выше.
4. **Случай решает.** Установите параметры с R₀ около 1 и перебирайте seed кубиком 🎲:
   в одних прогонах эпидемия гаснет сразу, в других — разрастается.
5. **Три болезни.** N = 400, k = 4, усреднение включено. Сохраните прогнозы для ОРВИ, гриппа и COVID-19
   и сравните кривые «Больные»: у COVID-19 пик выше, но из-за долгой инкубации наступает позже.
6. **Город детей и город взрослых.** Выберите COVID-19, сохраните прогноз с 70 % детей,
   затем с 10 % детей — и сравните, как возраст через инкубацию сдвигает волну.

## Ограничения

- Граф статичен: контакты не меняются со временем.
- Иммунитет после болезни пожизненный, повторного заражения нет.
- Нет смертности, вакцинации, карантина и других мер — это возможные направления развития.
- Параметры болезней приближённые (см. [Болезнь](#болезнь)); возраст влияет только на инкубацию,
  хотя в жизни он влияет и на число контактов, и на длительность заразности.
- Модель учебная и не предназначена для реальных эпидемиологических прогнозов.
