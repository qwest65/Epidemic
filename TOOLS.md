# Инструменты, использованные при создании сайта «Эпидемия на случайном графе»

*24.11.2026, дополнено 26.11.2026*

## Введение

В ходе работы был создан сайт, который показывает, как болезнь распространяется по сети знакомств между людьми. Сайт открывается в любом браузере по адресу [qwest65.github.io/Epidemic](https://qwest65.github.io/Epidemic/) и не требует установки программ.

В этом разделе перечислены инструменты, которые использовались при проектировании и создании сайта: что это за инструмент, для чего он был нужен и на каком этапе работы применялся.

## Этапы работы

Работа шла в семь этапов. На каждом использовались свои инструменты.

1. **Постановка задачи.** Сначала было составлено техническое задание (ТЗ): какие параметры вводит пользователь, что показывает экран, как идёт симуляция. Инструменты: текстовое описание задачи и ИИ-ассистент Claude, с которым ТЗ обсуждалось и уточнялось.
2. **Выбор математической модели.** Выбраны случайный граф Эрдёша — Реньи для сети контактов и модель SEIR для болезни. Обсуждались спорные места: как считать вероятность заражения, заразен ли человек в инкубации, какие диапазоны параметров имеют смысл.
3. **Написание программы.** По ТЗ создан один файл index.html на языках HTML, CSS и JavaScript с библиотеками D3.js и Chart.js. Код написан с помощью Claude Code.
4. **Проверка.** Сайт проверялся в браузере на экранах компьютера и телефона. Использовалась автоматическая проверка со скриншотами; найденные ошибки исправлены.
5. **Публикация.** Код сохранён в репозитории на GitHub и опубликован в интернете через GitHub Pages.
6. **Описание.** Написаны два документа: подробное техническое описание (README) и простая инструкция для пользователя (GUIDE).
7. **Доработка.** После просмотра готового сайта правки записывались от руки на бумаге, затем обсуждались и вносились. Так число людей увеличено до 900, а период симуляции ограничен 90 днями. Затем добавлены выбор болезни (ОРВИ, грипп, COVID-19 или своя), смешанное население из детей, подростков и взрослых с разным инкубационным периодом, до 100 начальных заражённых и своя дата начала у каждого прогноза. Главная доработка — сравнение прогнозов: несколько сценариев на одном графике по дням или датам, усреднение по 20 прогонам, таблица отличий и выгрузка графика (PNG) и данных (CSV) для отчёта. Последней добавлена анимация: заражение летит по связи «искрой», есть демо-режим с подписями для выступления и «дерево заражения» по поколениям. Её сначала проверили в отдельной ветке, а потом перенесли на сайт. Каждая готовая версия сайта сохраняется под своим номером.

## Перечень инструментов

### Математические модели

**Случайный граф Эрдёша — Реньи.** Граф — это схема из точек и линий. Здесь точки — люди, а линии — знакомства. Для каждой пары людей «подбрасывается монетка»: с заданной вероятностью они становятся знакомыми. Так получается случайная сеть контактов, по которой идёт болезнь.

**Модель SEIR.** Каждый человек находится в одной из четырёх групп: здоров (S), заражён без симптомов (E), болен (I), выздоровел (R). Вся симуляция — это правила, по которым люди переходят из группы в группу каждый день.

### Искусственный интеллект

**Claude и Claude Code** (компания Anthropic). Claude — ИИ-ассистент, с которым можно общаться обычным языком. Claude Code — его версия для программирования: он пишет код, запускает его, проверяет и сохраняет в репозиторий. ИИ помогал на всех этапах: обсуждение ТЗ, написание и проверка кода, публикация, описание. Задачу, параметры и правки определял автор работы, а предложения ИИ принимались или отклонялись после обсуждения.

### Языки и библиотеки

- **HTML** — задаёт структуру страницы: кнопки, ползунки, блоки.
- **CSS** — отвечает за внешний вид: тёмная тема, цвета, расположение блоков. Благодаря ему сайт подстраивается под экран телефона.
- **JavaScript** — язык программирования, на котором написана вся логика: построение графа, расчёт заражений по дням, подсчёт статистики.
- **Canvas** — встроенная в браузер «холст» для рисования. На нём рисуется сеть из сотен людей и тысяч связей без торможения, а также анимация заражений: искры, свечение, перестроение сети в дерево.
- **D3.js** — библиотека для визуализации данных. Она раскладывает точки графа по экрану так, чтобы знакомые оказались рядом, и даёт приближать и двигать картинку.
- **Chart.js** — библиотека для графиков. С её помощью строится график групп S, E, I, R по дням и график сравнения нескольких прогнозов с наложением.
- **CDN jsDelivr** — интернет-сервис, с которого сайт загружает библиотеки. Их не нужно скачивать и хранить вместе с сайтом.

### Хранение и публикация

- **Git** — система, которая запоминает каждую версию файлов. Готовые версии сайта отмечены номерами (v1.0, v1.1, v2.0, v2.1, v3.0, v3.1). Любую старую версию можно открыть или вернуть, а новые идеи можно пробовать в отдельной ветке, не трогая рабочий сайт.
- **GitHub** — сайт для хранения проектов. Весь код лежит в репозитории [qwest65/Epidemic](https://github.com/qwest65/Epidemic). Каждая правка оформлялась отдельным запросом на изменение (pull request), так что видно, что и когда менялось.
- **GitHub Pages** — бесплатный хостинг GitHub. После включения в настройках репозитория сайт сам обновляется при каждом изменении кода.

### Проверка и оформление

- **Браузер Google Chrome** — для просмотра сайта, настройки GitHub Pages и оценки результата.
- **Playwright** — программа, которая сама открывает сайт в браузере, нажимает кнопки и делает скриншоты. С её помощью проверено, что сайт работает на компьютере и телефоне и справляется с 900 людьми.
- **Markdown** — простой способ оформлять текст (заголовки, списки, таблицы). На нём написаны README и инструкция GUIDE; оба документа обновлялись после каждой доработки.
- **Бумага и ручка** — для списка правок после просмотра первой версии сайта.
